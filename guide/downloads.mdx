## 下载中心

所有下载任务（游戏安装、Mod、整合包、更新）都汇集在 **下载中心**，支持并行、暂停与实时进度。

## 界面

侧边栏点击 **下载** 进入：

- **实时进度**：每个任务显示速度、进度条、已完成/总大小
- **多任务并行**：多任务同时下载，互不阻塞
- **取消任务**：任务卡片上直接取消

## 下载加速

启动器内置多种加速机制（设置 → 下载设置）：

| 设置 | 作用 |
| :--- | :--- |
| **下载线程数** | 单任务的并发连接数，默认 64。网络差可调低 |
| **文件分块线程** | 大文件分块并行下载 |
| **下载超时** | 单请求超时时间（秒） |
| **HTTP/3** | 实验性，对支持的 CDN 启用 HTTP/3 传输 |
| **下载源自动选择** | 在官方源与 QML 镜像源间自动测速切换 |

下载慢或失败时优先尝试：**开启下载源自动选择**，或参考[下载镜像](/guide/mirror)手动配置。

## 资源文件命名

下载的 Mod 等资源文件可自定义命名格式（设置 → 下载设置 → 文件命名），支持：

- `中文名-版本` / `版本-中文名` / `中文名` / `英文原名` 等组合

按你管理 Mod 文件夹的习惯选择即可。
