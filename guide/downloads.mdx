## 下载中心

所有下载任务（游戏安装、Mod、整合包、更新）都汇集在 **下载中心**，支持并行、暂停与实时进度。

## 界面

侧边栏点击 **下载** 进入：

- **实时进度**：每个任务显示速度、进度条、已完成/总大小
- **多任务并行**：多任务同时下载，互不阻塞
- **取消任务**：任务卡片上直接取消

## 下载加速

启动器内置多种加速机制（设置 → 下载设置）：

| 设置 | 作用 |
| :--- | :--- |
| **下载线程数** | **同时下载的文件数量**（1–512，默认 64），不是单任务的连接数；网络差可调低 |
| **分片线程数** | 大文件分块并行下载：关闭 / 自动 / 1–16 |
| **下载超时** | 单个文件无响应超过此时间自动重试（0 = 不超时，1–120 秒） |
| **启用 HTTP/3 文件下载（实验性）** | 对支持的 CDN 启用 HTTP/3 传输 |
| **自动选择最快下载源 / 自动选择下载源 / 自动选择最快资源下载源** | 三组下载源各有独立开关，按延迟自动测速选择 |

下载慢或失败时优先尝试：**开启对应的自动选择开关**，或参考[下载镜像](/guide/mirror)手动配置。

## 资源文件命名

下载的 Mod 等资源文件可自定义命名格式（设置 → 下载设置 → 资源文件命名方式），支持：

- `[中文名]英文名-版本` / `[英文名]中文名-版本` / `中文名-英文名-版本` / `中文名-版本` / `英文名-版本` / `中文名` / `英文名`

按你管理 Mod 文件夹的习惯选择即可。
