## 插件系统

Qomicex 支持插件扩展：安装社区插件获得新功能，或自己动手开发。

## 安装插件

插件以 `.qplugin` 文件分发（本质是 zip 包），有三种安装途径：

- **插件商店**（若可用）：浏览社区插件一键安装
- **本地安装**：设置 → 插件 → 上传 `.qplugin` 文件
- **开发模式**：开发时把插件放进启动器数据目录的 `plugins-dev/` 文件夹

安装后需 **启用** 插件才生效；停用不删除数据，重新启用即恢复。

## 插件能做什么

| 能力 | 例子 |
| :--- | :--- |
| 主页小组件 | 天气、服务器状态、倒计时卡片（见[主页小组件](/guide/dashboard-widget)） |
| 侧边栏入口 | 在侧边栏添加插件页面或悬浮窗按钮 |
| 悬浮窗 | 屏幕上的独立小窗口（如音乐控件、快捷工具） |
| 完整页面 | 挂载在 `/plugins/p/:插件id` 的功能页 |
| 主题与图标 | 自定义主题色、图标包、字体 |
| 前置插件库 | 不带界面的能力库，供其他插件调用（如 Markdown 渲染库） |

## 权限说明

部分能力需要授权，启动器会弹窗询问：

- **文件读写**：插件请求读写某个文件/目录时逐次授权
- **网络代理**：插件经启动器代理访问外网
- **执行命令**：调用系统命令（PowerShell/Shell），默认 15 秒超时

插件拥有较强的系统能力（文件、网络、命令执行）。安装来源不明的插件前请确认其可信。

## 管理插件

在 **设置 → 插件** 中：

- 启用 / 停用 / 卸载
- 修改插件设置：切到「插件设置」子 tab，左侧选择插件，右侧即该插件提供的设置界面
- 查看插件权限与依赖关系

带依赖的插件会自动检查前置：缺前置时拒装并提示；前置被停用时插件自动禁用。
