## 优化配置

游戏卡、启动慢、下载慢？按需调整这几处，大多数性能问题都能解决。

## 选对 Java

启动器需要 **Java 8 / 17 / 21** 三个版本，不同游戏版本自动选用：老版本（1.16 及以下）用 Java 8，1.17–1.20.4 用 Java 17，1.20.5+ 用 Java 21。

- **优先让启动器下载**：设置 → Java 运行时 → 下载。自动下载的 JDK 与游戏兼容性最好
- 本机自带的 Java 可通过扫描收编，但来源不明的 JRE（如某些捆绑软件装的）可能损坏，被标记异常时移除即可

## 内存分配

设置 → 启动设置 → 内存：

| 机器内存 | 建议 |
| :--- | :--- |
| 8GB 及以下 | **自动分配**（启动器按可用内存计算，不会挤占系统） |
| 16GB | 原版/轻量 Mod 4–6GB；中大型整合包 6–8GB |
| 32GB+ | 大型整合包 8–12GB 足够，**不是越多越好** |

Java 堆过大导致垃圾回收停顿变长，游戏会出现规律性卡顿。给够用即可。

## 启动参数

设置 → 启动设置 → JVM 参数。**整合包作者若给了推荐参数，以整合包为准**；否则保持默认（启动器已内置合理的垃圾回收参数）。自己调优属于进阶玩法，动之前先记下原值。

## 下载与网络

- 下载慢：开启 **下载源自动选择**，或用[镜像源](/guide/mirror)手动替换域名
- 网页/资源中心打不开：配置代理（设置 → 网络设置），仅影响启动器，不影响游戏
- 代理下证书报错：临时开启 **忽略 SSL 证书** 排障，确认问题后关闭

## 界面流畅度

低配机器优先做这三件事（设置 → 外观）：

- **组件材质** 改回 default（液态玻璃/亚克力/毛玻璃都有合成开销）
- 调低或关闭 **动画**
- **最大帧率** 限制到 60（省电且不易过热）

## 数据与缓存

- 版本列表缓存（设置 → 储存与缓存）：CurseForge/NeoForge 列表拉取慢时延长缓存时间
- 清理下载任务列表、导出/清理日志：设置 → 工具箱与日志分区
