## 设置详解

设置页位于侧边栏 **设置**，左侧按分类导航。本篇按分类解释每个设置项的作用与推荐值。

- **全局设置 vs 实例设置**：本页的启动设置（内存、Java、JVM 参数）是**全局默认值**；单个实例可在 实例详情 → 设置 中覆盖（见[实例管理](/guide/instances)）。
- 性能优化专题（内存怎么给、Java 怎么选、下载加速）见 [优化配置](/guide/optimize)。

## 启动器设置（基础）

| 设置 | 说明 | 建议 |
| :--- | :--- | :--- |
| 语言 | 界面显示语言 | — |
| 数据目录 | 启动器配置与数据的存放位置 | 不了解勿改 |
| 版本隔离 | 各实例数据独立存放（推荐开启） | ✅ 开启 |
| 启动后关闭启动器 | 游戏启动后最小化/退出启动器 | 按习惯 |
| 自动上报严重错误 | 崩溃日志自动上报帮助改进（不上报个人内容） | ✅ 推荐 |
| 遥测 | 匿名功能使用统计（opt-in，默认关） | 按意愿 |

## 启动设置

- **内存分配**：`auto` 由启动器按物理内存自动计算，或手动指定最大内存。**8GB 及以下机器建议 auto**，玩大整合包可手动给 6–8GB
- **默认 Java**：全局默认 Java 运行时（实例可单独覆盖）；Java 未安装时可在 Java 分区一键下载
- **JVM 参数**：附加启动参数，玩 Large Modpack 通常无需手填

## 下载设置

见 [下载中心](/guide/downloads#下载加速)。

## 储存与缓存

- **版本列表缓存时长**：CurseForge / NeoForge 版本列表缓存时间，缩短 = 更及时、更长 = 更省请求
- **并发与 TTL**：CurseForge 请求并发数与缓存存活时间，一般不动

## 网络设置

| 设置 | 说明 |
| :--- | :--- |
| 代理模式 | 关闭 / 跟随系统 / HTTP(S) 代理 / SOCKS5 代理 |
| 代理地址 | `host:port`，如 `127.0.0.1:7890` |
| 忽略 SSL 证书 | 跳过证书校验（解决部分代理的证书劫持；有安全风险，排障时临时开） |
| HTTP/1.1 并行 | 强制并行下载走 HTTP/1.1，兼容某些代理 |

这里的代理作用于**启动器自身的请求**（资源搜索、下载等），不改变游戏内网络。

## Java 运行时

- 已扫描到的 Java 列表与默认运行时选择
- **下载 Java**：自动下载适配的 JDK（推荐 Mojang 官方源），无需手动装 Java
- **手动添加**：指定本机已有 Java 的路径

## 外观

| 设置 | 说明 |
| :--- | :--- |
| 主题模式 / 预设 / 主题色 | 深浅色、主题预设（默认/拿铁/冰沙…）、强调色（可跟随背景莫奈取色） |
| 组件材质 | default / 毛玻璃 / 亚克力 / Aero / 液态玻璃，卡片质感 |
| 背景 | 自定义背景图（支持随机）、叠加不透明度、模糊度 |
| 动画 | 界面动画开关与速度、最大帧率限制 |
| 窗口圆角 | 窗口圆角开关与半径（Windows） |
| 字体 | 全局 UI 字体 |
| 水印 | 主页水印文字开关与内容 |
