## 设置详解

设置页位于侧边栏 **设置**，左侧按分类导航，共 13 个分类：启动器设置、基础设置、启动设置、下载设置、储存与缓存、网络设置、Java 运行时、插件、外观、工具箱、日志、关于、调试。

- **全局设置 vs 实例设置**：本页的内存、Java、JVM 参数是**全局默认值**；单个实例可在 实例详情 → 设置 中覆盖（见[实例管理](/guide/instances)）。
- 性能优化专题（内存怎么给、Java 怎么选、下载加速）见 [优化配置](/guide/optimize)。
- **调试**分类默认隐藏，需在关于页解锁后才会出现。

## 下载设置

| 设置 | 说明 |
| :--- | :--- |
| 下载线程数 | **同时下载的文件数量**（1–512，默认 64），数值越大越快但更占带宽 |
| 分片线程数 | 大文件分块并行下载：关闭 / 自动 / 1–16 |
| 下载超时（秒） | 单个文件无响应超过此时间自动重试（0 = 不超时，1–120） |
| 启用 HTTP/3 文件下载（实验性） | 对支持的 CDN 启用 HTTP/3 |
| 强制 HTTP/1.1 并行连接下载 | 兼容部分代理 |
| 跳过 JAR 级版本探测 | 加快版本扫描 |
| 资源文件命名方式 | `[中文名]英文名-版本` / `[英文名]中文名-版本` / `中文名-英文名-版本` / `中文名-版本` / `英文名-版本` / `中文名` / `英文名` |

下载设置还包含三组下载源，每组都有独立的「自动选择」开关与延迟测速：

| 下载源 | 可选值 |
| :--- | :--- |
| 下载源（游戏本体） | 官方源 / BMCLAPI 镜像 + 自动选择最快下载源 |
| 文件下载源 | 官方源 / 镜像源 + 自动选择下载源 |
| 资源下载源 | Modrinth / CurseForge 官方 vs MCIM 镜像 + 自动选择最快资源下载源 |

## 储存与缓存

- **数据目录**：启动器数据存放位置，更改后需重启生效。
- **版本列表缓存**：清理 Forge 版本列表的 HTML 缓存文件。
- **CurseForge 版本列表并发数**：同时拉取的页面数（1–20，默认 10）。
- **CurseForge 版本列表缓存有效期（秒）**：0 = 永久缓存（直到重启或手动清除），默认 300 秒。
- **NeoForge / FTB 版本缓存、模组列表缓存、模组更新缓存、整合包导入临时文件**：均提供对应的清理按钮。

## 网络设置

| 设置 | 说明 |
| :--- | :--- |
| 代理类型 | 不使用代理 / 使用系统代理 / HTTP(S) 代理 / SOCKS5 代理 |
| 代理服务器地址 | `host:port`，如 `127.0.0.1:7890` |
| 忽略 SSL 证书校验 | 跳过证书校验（解决部分代理的证书劫持；有安全风险，排障时临时开） |
| 联机节点 | 自定义 EasyTier 中继节点，支持 `tcp/udp/wg/quic/ws/wss` 等协议；自定义节点优先，留空则只用官方节点 |
| 系统集成 | 关联 / 取消关联 `qomicex-launcher://` 链接 |

这里的代理作用于**启动器自身的请求**（资源搜索、下载等），不改变游戏内网络。

## Java 运行时

- **快速扫描 / 深度扫描 / 刷新列表**：检测本机 Java 运行时，可「显示无效项」查看不可用项。
- **下载 Java**：在下载弹窗里选择发行版（带 (推荐) 标记）、Java 主版本、平台、架构与目标目录。
- **手动添加**：指定本机已有 Java 可执行文件的完整路径。
- **默认配置**（本页下方）：默认 Java 运行时（可自动选择）、内存分配、额外 JVM 参数——这三项就是下方 [内存与 JVM 参数](#内存与-jvm-参数)。

### 内存与 JVM 参数

- **内存分配**：选「自动」时按可用内存的 70% 计算（最小 512 MiB）；也可手动拖动，范围 512 MiB 至可用内存上限，步进 256 MiB。
- **额外 JVM 参数**：启动 Minecraft 时附加的 JVM 参数，整合包作者若给了推荐值再填写。

<Warning>
非专业玩家请勿修改 JVM 参数，错误的参数可能导致游戏无法启动。
</Warning>

## 外观

| 设置 | 说明 |
| :--- | :--- |
| 主题模式 / 主题预设 / 主题色 | 深浅色；预设为 Qomicex Default 与 Catppuccin（Latte / Frappé / Macchiato / Mocha）；强调色可自定义或「跟随背景（莫奈取色）」 |
| 组件材质 | 默认 / 毛玻璃 / 亚克力玻璃 / Aero / 液态玻璃（预览）。液态玻璃启用前会弹确认并提示性能开销；非默认材质会多出模糊强度滑杆 |
| 卡片透明度 / 卡片边框颜色 / 卡片边框厚度 | 默认材质下分类卡片的不透明度（默认 50）、边框颜色与粗细（0–4px，0 为无边框） |
| 对话框透明度 | 对话框背景不透明度，独立于组件材质（默认 75） |
| 页面动画 / GPU 硬件加速 / 动画速度 | 页面切换与弹窗过渡动画、硬件加速开关（仅在开启页面动画时出现）、动画速度 0.25x–2x |
| 帧率上限 | 不限 / 30 / 60 / 120 / 144 |
| 窗口圆角 | 圆角开关与半径（直角 / 默认 8px / 大圆角），仅在不使用系统框架时生效 |
| 界面字体 | 选择系统已安装字体，全局 UI 立即生效 |
| 背景 | 背景图片（支持每次启动随机挑选、播放动图、播放视频）、叠加不透明度、模糊度 |
| 水印 | 主页水印文字与副标题 |

## 工具箱

工具箱当前只有一项能力：**自定义文件下载**——粘贴 URL 列表批量下载到指定文件夹。

## 日志

日志管理：保留最近 10 个日志文件，支持搜索、按级别过滤、导出全部或导出 `.gz`。
