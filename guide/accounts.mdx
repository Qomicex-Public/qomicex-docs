## 账户管理

启动器支持多种登录方式，全部账户集中在 **账户管理** 页面管理。

## 添加账户

侧边栏点击 **账户** → **添加账户**，按提示选择登录方式：

| 登录方式 | 说明 |
| :--- | :--- |
| **微软** | 正版登录，走 Microsoft OAuth 流程，浏览器内完成授权 |
| **离线** | 用户名直接进入，供单机/离线服务器使用（可选填 UUID，留空则自动生成） |
| **Yggdrasil** | 外置登录。提供「预设服务器」快捷按钮（LittleSkin、Blessing Skin），也可填自定义服务器地址；支持 OAuth 与密码两种模式 |
| **统一通行证** | 部分 Minecraft 服务器使用的认证系统，需要输入服务器 ID（如 `lilu`） |

<Note>
部分语言的界面下，需要**先登录至少 1 个 Microsoft 正版账户**，才能添加离线或第三方账户；此时对应标签页会置灰。
</Note>

## 设为默认

主页启动栏与启动流程使用**默认账户**。在账户列表将某个账户 **设为默认**，或在主页账户卡片上点击下拉箭头快速切换。

首次启动游戏时会弹出账户选择/添加向导，按提示操作即可，无需提前到设置里配置。

## 皮肤与披风

- **微软账户**：功能最完整——可上传皮肤（含经典 / 纤细手臂模型选择）、重置皮肤、切换官方披风，也会自动刷新皮肤。
- **Yggdrasil / 统一通行证账户**：只能「刷新皮肤」；若该账户配置了服务器地址，还会出现「前往皮肤站」按钮跳转到外部皮肤站管理。启动器内不提供上传。
- **离线账户**：账户详情页不提供皮肤与披风操作。

## 常见问题

- **微软登录提示令牌过期**：启动或进入游戏时遇到过期令牌，会弹出 Microsoft 重新授权窗口，按提示重新登录即可；过期账户也可在账户页手动重新登录。
- **离线账户进不去正版服务器**：离线登录无法进入需要正版验证的服务器，请使用微软登录。
- **账户数据文件损坏提示**：本机机器码变化可能导致加密数据无法解密，按提示重新添加账户即可。
