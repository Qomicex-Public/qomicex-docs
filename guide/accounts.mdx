## 账户管理

启动器支持多种登录方式，全部账户集中在 **账户管理** 页面管理。

## 添加账户

侧边栏点击 **账户** → **添加账户**，按提示选择登录方式：

| 登录方式 | 说明 |
| :--- | :--- |
| **微软** | 正版登录，走 Microsoft OAuth 流程，浏览器内完成授权 |
| **离线** | 用户名直接进入，供单机/离线服务器使用 |
| **统一通** | extchu 统一通行证（外置登入） |
| **LittleSkin** | LittleSkin 皮肤站（Yggdrasil 外置登录） |
| **自定义 Yggdrasil** | 自建/第三方认证服务器，填入服务器地址（API Root）即可 |

## 设为默认

主页启动栏与启动流程使用**默认账户**。在账户列表将某个账户 **设为默认**，或在主页账户卡片上点击下拉箭头快速切换。

首次启动游戏时会弹出账户选择/添加向导，按提示操作即可，无需提前到设置里配置。

## 皮肤与披风

- **微软 / Yggdrasil 系账户**：皮肤与披风从认证服务器加载，在账户详情页可查看与更换（支持从皮肤站或本地上传）
- **离线账户**：可从皮肤库挑选皮肤，或上传本地皮肤文件

## 常见问题

- **微软登录提示令牌过期**：账户卡片会标记过期，点击后重新走一次登录即可；启动时遇到也会弹出重新授权窗口。
- **离线账户进不去正版服务器**：离线登录无法进入需要正版验证的服务器，请使用微软登录。
- **账户数据文件损坏提示**：本机机器码变化可能导致加密数据无法解密，按提示重新添加账户即可。
