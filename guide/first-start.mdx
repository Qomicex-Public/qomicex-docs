## 初次启动

首次启动 Qomicex 会进入**初始化向导**，几分钟完成基础配置。

## 两种模式

| 模式 | 适合 | 内容 |
| :--- | :--- | :--- |
| **快速设置** | 大多数用户 | 语言、主题、Java、内存——启动器自动推荐，少量确认即可 |
| **自定义设置** | 想自己掌控的用户 | 上述内容之外，额外包含下载源、数据目录与游戏目录 |

## 向导步骤

- **语言** — 选择界面语言，立即生效，之后可随时在设置中更改
- **主题** — 深色 / 浅色，可在设置中随时切换
- **目录**（仅自定义模式）— 数据目录存放启动器配置，游戏目录（.minecraft）存放游戏文件
- **下载源**（仅自定义模式）— 对各下载源自动测速，选择延迟最低的；也可勾选"自动选择最优"
- **Java 运行时** — 启动器需要 **Java 8 / 17 / 21** 三个版本，自动深度扫描本机；缺失的版本可点击在线下载
- **内存** — 推荐**自动分配**（按系统可用内存计算），也可手动指定最大内存
- **完成** — 确认配置摘要，开始使用

可以向导中选择跳过 Java 配置，但 Java 环境不完整时**部分游戏版本可能无法启动**。之后可在 设置 → Java 运行时 中补齐。

不用重新下载。进入主页后到实例页点击 **导入**，选择现有的 `.minecraft` 目录即可收编已有版本，见[安装游戏 → 迁移已有游戏](/guide/installing-games#迁移已有游戏)。
