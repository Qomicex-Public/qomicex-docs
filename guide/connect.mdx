## 多人联机

启动器内置多人联机功能：无需公网 IP、无需开服务器，即可和朋友一起玩单人世界。

## 快速开始

侧边栏点击 **联机** 进入。

### 房主（建房间的人）

- 选择要联机的**本地实例**
- 点击 **创建房间**，得到一个**房间码**
- 把房间码发给朋友
- 保持页面开启，等待玩家加入

### 玩家（加入的人）

- 输入房主给的**房间码**
- 启动器会自动检测 **NAT 类型** 并建立连接
- 加入后选择自己的本地实例，启动器会自动比对 Mod

## Mod 一致性检查

加入时启动器会把**房主的 Mod 列表**与你本地实例逐一比对：

| 状态 | 含义 | 处理 |
| :--- | :--- | :--- |
| **一致** | 你与房主 Mod 完全相同 | 直接 **快捷启动** |
| **缺失** | 你缺某些 Mod | 按列表到资源中心补齐后启动 |
| **不一致** | 版本或数量有差异 | 可 **忽略差异强制启动**（有崩游戏风险，自担） |

本地有多个实例时，启动器自动选**与房主 Mods 重叠最多的实例**作为推荐，缺失列表也按它计算。

## 房主管理

房主在房间内可以：

- **查看玩家列表**：实时在线成员
- **踢出玩家**：将捣乱的玩家移出房间（会同时物理封禁其网络标识，防止自动重连）
- **重新加入审核**：被踢玩家尝试回流时弹窗确认——允许则放行，拒绝则继续拦截，可静默拒绝（不再弹窗）
- **解封**：在已踢玩家列表中解除封禁

## 连接失败排查

| 现象 | 可能原因与处理 |
| :--- | :--- |
| NAT 检测失败 | 网络受限（公司/校园网常见），换热点试试 |
| 一直连不上房主 | 双方至少一方网络过严；房主可重建房间再试；启动器后台存在残留et进程，重启启动器再试 |
| 能连上但游戏进不去 | 确认双方游戏版本与 Mod 一致；查看房主是否已进入世界（单人世界需先开放局域网或由联机层代理） |
| 踢了还能进 | 对方更换了网络标识，重新踢出并考虑静默拒绝 |

Radmin VPN、Hamachi 等虚拟网卡软件可能与联机冲突。启动器已自动规避常见抢占问题，但连接异常时建议先退出此类软件再试。
