## 资源中心

资源中心聚合 **Modrinth** 与 **CurseForge** 两大平台的资源，无需打开浏览器即可搜索和安装 Mod、整合包、资源包、光影包等。

## 搜索资源

侧边栏点击 **资源中心** 进入：

- 选择分类：**Mod / 整合包 / 资源包 / 光影包 / 存档**
- 输入关键词搜索，或浏览热门与推荐
- 用筛选器按 **游戏版本**、**加载器**（Forge / Fabric / NeoForge 等）、**来源**（Modrinth / CurseForge）过滤

## 安装到实例

进入资源详情页后：

- 切换到 **版本** 标签，选择与你的实例匹配的 **游戏版本 + 加载器** 版本
- 点击 **安装**，选择目标实例
- 安装进度可在 **下载中心** 查看

安装器会按你选择的实例（游戏版本 + 加载器）自动过滤可用版本，避免装错。

## 整合包

整合包（Modpack）是"一键配齐"的游戏环境：包含游戏版本、加载器、全部 Mod 与配置。

在资源中心选择 **整合包** 分类搜索 → 详情页选版本 → **安装**，启动器自动创建新实例并下载全部内容。

整合包的完整说明（本地导入、MultiMC 迁移、Mod 管理、更新与导出）见 **[整合包支持](/guide/modpack-support)**。
