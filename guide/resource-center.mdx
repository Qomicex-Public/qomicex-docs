## 资源中心

资源中心聚合 **Modrinth** 与 **CurseForge** 两大平台的资源，无需打开浏览器即可搜索和安装 Mod、整合包、资源包、光影包等。

## 搜索资源

侧边栏点击 **资源中心** 进入：

- 选择分类：**聚合 / 模组 / 整合包 / 光影 / 材质包 / 数据包 / 存档**
- 输入关键词搜索，或切换到 **收藏** 查看已收藏的资源
- 用筛选器按 **游戏版本**、**加载器**（Forge / Fabric / NeoForge 等）、**来源**（聚合 / Modrinth / CurseForge / FTB / Technic）过滤

## 安装到实例

进入资源详情页后：

- 点击 **安装**，在弹出的安装对话框中先 **选择实例**
- 选定实例后，版本列表只显示与该实例 **游戏版本 + 加载器** 匹配的版本，从中挑选即可
- 安装进度可在 **下载中心** 查看

实例优先的筛选方式会自动过滤掉不兼容的版本，避免装错。

## 整合包

整合包（Modpack）是"一键配齐"的游戏环境：包含游戏版本、加载器、全部 Mod 与配置。

在资源中心选择 **整合包** 分类搜索 → 详情页选版本 → **安装**，启动器自动创建新实例并下载全部内容。

整合包的完整说明（本地导入、MultiMC 迁移、Mod 管理、更新与导出）见 **[整合包支持](/guide/modpack-support)**。
