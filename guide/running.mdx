## 运行中

启动游戏后，**运行中**页面负责监控和管理正在运行的游戏实例。

## 实例运行状态

侧边栏点击 **运行中**（有游戏在跑时也可从主页/实例页进入）：

- 查看正在运行的实例与启动时长
- 直接结束游戏进程

## 实时日志窗口

点击**实例详情**中的**测速游戏**可打开 **实时游戏日志** 窗口：

- 日志**实时滚动**输出，可暂停跟随
- 按级别着色过滤：INFO / WARN / ERROR / DEBUG / FATAL
- **关键字搜索**快速定位异常
- 网络请求日志开关（诊断联机/下载问题）
- **停止游戏**：确认后结束进程（未保存的世界进度会丢失）

游戏启动失败或卡在启动界面时，实时日志通常会显示最后一段输出——把它复制到[日志分析](/guide/log-analysis)即可获得诊断。

## 崩溃处理

游戏崩溃时：

- 运行中页面 / 日志窗口提示 **游戏异常退出**
- 进入崩溃分析，启动器解析崩溃报告并给出诊断（常见原因：Mod 冲突、内存不足、版本不匹配）
- 需要求助时生成 mclo.gs 链接分享（见[日志分析](/guide/log-analysis)）
