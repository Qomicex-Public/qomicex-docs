## 主页小组件

主页是一个**可自由编辑的小组件桌面**，类似手机桌面的小组件：水印、账户、公告、实例启动栏都是一个个"组件"，你可以随意移动、调整大小、隐藏它们，装了提供小组件的插件后还能把插件组件也摆上来。

## 认识主页

默认布局长这样：

| 区域 | 组件 | 作用 |
| :--- | :--- | :--- |
| 中央 | 水印 | 显示启动器名称（可在设置中自定义文字或关闭） |
| 右上 | 账户 | 当前默认账户，点箭头可快速切换账户 |
| 右侧 | 公告 | 滚动显示官方公告，点开查看全文 |
| 底部 | 实例启动栏 | 显示默认实例信息 + 大大的启动按钮 |

## 编辑布局

点击主页**右上角的「编辑布局」**按钮（铅笔图标），进入编辑模式：

| 操作 | 怎么做 |
| :--- | :--- |
| **移动组件** | 按住组件直接拖到想要的位置 |
| **调整大小** | 拖动组件**右下角**（或右侧、下侧边缘）的手柄 |
| **移除组件** | 鼠标悬停在组件上，点右上角的 **✕** |
| **添加组件** | 工具条上的 **＋**，在面板里点击想恢复的组件 |
| **恢复隐藏的组件** | 工具条上的 **👁** 图标，每个隐藏组件对应一个 |
| **恢复默认布局** | 工具条上的 **↺** 按钮 |
| **保存并退出** | 工具条上的 **「完成」** 按钮 |

组件不会被强制对齐堆叠——拖走一个组件后，其他组件**保持原位不动**，留出的空位你可以随意利用，就像关闭了"自动排列图标"的电脑桌面。

编辑模式下组件只负责被拖动/缩放，里面的按钮不会响应点击。完成后记得点「完成」保存。

## 组件会自己适应大小

每个组件都会根据占据的格子数**智能显示内容**：

- **小尺寸**（如 1×1）：只显示最关键的信息。比如账户组件缩小后只显示头像和名字，公告缩小后只显示标题。
- **大尺寸**：显示更详细的内容。比如公告放大后会显示正文摘要，实例栏放大后会显示上次游玩时间等。

把组件拉大缩小试试看，内容会自动切换。

## 布局保存在哪

你的布局调整会**自动保存**在本机（浏览器本地存储），不用手动保存，重启启动器后依然生效。

- 「恢复默认布局」会把所有组件放回出厂位置，你隐藏过的组件也会全部恢复显示。
- 升级启动器**不会丢失**你的布局。

## 插件组件

安装了提供小组件的插件后（见插件文档的[主页小组件](/plugins/dashboard-widget)章节），插件组件也会出现在主页网格中：

- 与内置组件一样可以拖动、缩放、隐藏；
- 插件停用或卸载后组件自动消失，重新启用后**原位恢复**；
- 组件内容完全由插件决定，例如天气、服务器状态、倒计时等。

组件被隐藏后不会显示在网格里。进入编辑模式，点工具条上的 **＋** 或 **👁** 把它找回来。
