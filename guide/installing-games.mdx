## 安装游戏

启动器支持三种方式获得可玩的游戏：**通过下载**全新安装、**安装整合包**一键配齐，或**迁移已有游戏**把电脑上现成的 .minecraft 收编进启动器。

## 通过下载

适合从零开始装一个干净的游戏。

- 侧边栏点击 **实例** → **安装**
- 选择 **游戏版本**（原版版本号）
- 选择 **加载器** 及其版本（Forge / Fabric / NeoForge / Quilt，玩原版选"无"）
- 确认实例名称与图标，开始安装

安装任务可在[下载中心](/guide/downloads)查看进度。完成后实例出现在列表中，选好 [Java](/guide/settings#java-运行时) 即可启动。

首次启动前启动器会引导你扫描或一键下载合适的 Java，见[设置详解 → Java 运行时](/guide/settings#java-运行时)。

## 安装整合包

整合包 = 游戏版本 + 加载器 + 全套 Mod + 预配置，**一键装好整个游戏环境**。

### 从资源中心安装

- 进入[资源中心](/guide/resource-center)，分类选 **整合包**
- 挑选整合包（按游戏版本、加载器筛选），进入详情页
- 选择版本 → **安装** → 自动创建实例并下载全部内容

### 从本地文件安装

手里已有整合包文件（`.zip`）时：

- 实例页面点击 **导入 → 安装整合包**
- 选择整合包压缩包，支持：

| 格式 | 来源 |
| :--- | :--- |
| CurseForge 整合包 | 从 CurseForge 网站下载的 zip |
| Modrinth 整合包（`.mrpack`） | 从 Modrinth 网站下载 |
| MultiMC / Prism 启动器实例 | 从其他启动器导出的实例 zip |

- 确认实例名与游戏目录，启动器自动解析并下载全部依赖

## 迁移已有游戏

电脑上已经用其他启动器（官方启动器、PCL、HMCL 等）装好的游戏，可以**直接收编进启动器**，无需重新下载：

- 实例页面点击左上角的目录组合框打开**目录列表**，点击**管理**打开目录管理
- 点击**浏览添加**，选择你的 **`.minecraft` 游戏目录**（目录下需包含 `versions/` 文件夹）
- 启动器扫描目录下所有版本，标记每个版本的可用状态

可以在 **目录列表** 中保存多个常用游戏目录（如不同启动器的 `.minecraft`），启动时直接从已保存的目录里挑选版本，不用每次翻文件夹。


## 补全文件

迁移或手动添加的实例若文件不全（如缺 `libraries`、`assets`），启动游戏前会提示。在 **实例详情 → 设置** 中点击 **补全文件**，启动器扫描缺失的游戏文件并自动下载——只补缺的，不动你已有的数据。
