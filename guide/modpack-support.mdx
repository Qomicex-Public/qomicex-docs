## 整合包支持

整合包（Modpack）是"开箱即玩"的完整游戏环境：预配置的游戏版本、加载器、全套 Mod 与设置。启动器对两大平台及主流打包格式提供完整支持。

## 安装整合包

三种途径，详见[安装游戏 → 安装整合包](/guide/installing-games#安装整合包)：

- **资源中心**搜索安装（Modrinth / CurseForge 在线整合包）
- **本地导入** CurseForge zip / Modrinth `.mrpack` / Qomicex `.qmodpack` / Technic 整合包
- **导入 MultiMC / Prism 启动器实例**（含嵌套实例目录的 zip，或直接选择实例文件夹）

安装后自动创建独立实例，所有依赖自动下载。

## 安装后

- 整合包实例与普通实例完全一致：可进详情页管理 Mod、存档、设置
- 下载任务在[下载中心](/guide/downloads)可见；中断的任务需手动恢复——在下载中心点 **重试** 或 **继续**，缺游戏文件时用 **补全文件** 补齐
- 顺手 **固定到主页**，配合主页启动栏一键开玩

## Mod 管理

整合包的 Mod 不建议手动增删（会破坏作者的配置预期），需要微调时：

- 实例详情 → **Mod**：查看清单、单个启停
- 前置依赖缺失时启动器会自动提示补齐
- 需要加 Mod 用[资源中心](/guide/resource-center)按实例匹配版本安装

## 更新整合包

- **在线整合包**：资源中心详情页有新版本时重新安装，或对单个 Mod 走实例内 **更新**
- Mod 层面的批量更新：实例详情 → Mod → **更新**

## 导出整合包

实例可导出为整合包分享给朋友：**实例详情 → 概况 → 快速操作 → 导出整合包**。导出时可选择格式——**CurseForge zip / Modrinth `mrpack` / Qomicex `.qmodpack`**——生成的整合包包含实例配置与 Mod 清单（默认不含存档、截图等个人数据，可在导出时手动勾选）。
