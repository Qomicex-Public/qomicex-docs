## 问题反馈

遇到 Bug 或想提建议？按下面的方式反馈，附上合适的信息能让问题更快解决。

## 反馈渠道

- **GitHub Issues**：前往 [Qomicex.Tauri 仓库](https://github.com/Qomicex-Public/Qomicex.Tauri/issues) 提交 issue
- **自动上报**：设置 → 启动器设置 → **自动上报严重错误日志** 开启后，崩溃日志会自动上报（仅含错误类型与运行环境，不含个人内容）

## 提交前

- 先翻一遍 [常见问题](/guide/faq)——很多问题已有答案
- 尝试在 [日志分析](/guide/log-analysis) 中分析日志，多数崩溃能直接得到原因

## 附上这些信息

| 信息 | 获取方式 |
| :--- | :--- |
| 启动器版本 | 设置 → 关于 |
| 操作系统与架构 | Windows 设置 / `systeminfo` 等 |
| 日志文件 | 设置 → 日志 → **导出全部**（或单个导出 `.gz`） |
| 崩溃报告链接 | 崩溃分析时生成 **mclo.gs** 短链接 |
| 复现步骤 | 做了什么操作、预期什么、实际什么 |

启动器只保留最近 10 条日志文件，导出时超长内容仅截取尾部 2MB，直接把导出的文件发出来即可。

## 提交规范

- 一个 issue 只描述**一个问题**，便于追踪
- 标题写清现象，如「启动 1.20.1 Fabric 实例闪退」而不是「不能用」
- Bug 报告附日志；功能建议说明使用场景
