## 快速上手

介绍如何安装与开始使用。

## 安装

从[官方网站](https://www.qomicex.top/) 或 [GitHub 发布页](https://github.com/Qomicex-Public/Qomicex.Tauri/releases/) 获取对应系统的安装包。

![下载页面](/images/tutorial/download.webp)

选择合适的 **系统** 及 **架构**，即可选择一个 **下载源** 进行下载：

- 国内推荐第一个和第二个下载源，国外推荐第三个

## 快速开始

- **Windows** — 运行 `.exe` 安装包，按向导完成安装。完成后从开始菜单启动。
- **macOS** — 挂载 `.dmg` 文件，将 Qomicex Launcher 拖入 Applications 文件夹。首次启动需在「安全性与隐私」中允许打开。
- **Linux** — 运行 `.AppImage`（`chmod +x` 后直接运行），或通过包管理器安装 `.deb` / `.rpm` 包。

## 环境要求

| 平台 | 支持架构 | 最低系统版本 | 支持状态 | 安装包/方式 |
| :--- | :--- | :--- | :--- | :--- |
| **Windows** | `x64`, `ARM64` | Windows 10 1809+ | ✅ | `.exe`（NSIS 安装器）|
| **macOS** | `x64`（Intel）<br></br>`ARM64`（Apple Silicon） | macOS 10.15+ | ✅ | `.dmg` / `.app` |
| **Linux** | `x64`, `ARM64`<br></br>`LoongArch64` (理论可用但无机器)<br></br>`RISC-V 64`(实验性,推进中) | Ubuntu 20.04+ / Fedora 34+ / glibc 2.28+ | ✅  | `.deb` / `.rpm` / `AppImage` |
