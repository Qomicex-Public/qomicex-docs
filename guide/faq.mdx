## 常见问题

收集使用中最高频的问题。没找到答案？参考[问题反馈](/guide/report-issue)。

## 启动与 Java

**提示"未检测到 Java 运行时"**

设置 → Java 运行时 → 点击 **快速扫描** 自动检测系统 Java；没有就点 **下载** 在线安装。启动器需要 Java 8 / 17 / 21 三个版本，不同游戏版本会自动选用合适的那个。

**游戏启动闪退 / 崩溃**

用 [日志分析](/guide/log-analysis) 粘贴日志或直接分析崩溃报告，常见原因是 Mod 冲突、内存不足、Java 版本不匹配。

**内存不足（OutOfMemoryError）**

调大内存分配：设置 → 启动设置 → 内存。大整合包建议 6–8GB，见[优化配置](/guide/optimize)。

## 账户

**微软登录提示令牌过期**

Microsoft 登录令牌有有效期，过期后启动器会弹出重新授权窗口，重新登录一次即可。

**提示"账户数据文件已损坏或机器码变更"**

账户数据是加密绑机的，重装系统/换硬件后无法解密。数据已被自动清除，重新添加账户即可。

**离线账户进不去服务器**

离线登录无法进入需要正版验证的服务器；进外置登录（LittleSkin / 统一通）服务器请用对应方式登录。

## 下载与资源

**下载很慢或失败**

- 确认 设置 → 下载设置 → **下载源自动选择** 已开启
- 试试手动替换镜像域名，见[下载镜像](/guide/mirror)
- 代理用户检查网络设置中的代理配置

**资源搜索没有结果**

确认筛选条件（游戏版本 / 加载器）与预期一致；CurseForge 与 Modrinth 的收录不同，可切换来源再搜。

## 联机

**NAT 检测失败 / 一直连不上**

网络受限环境（公司/校园网）常见，换手机热点试试；详见[多人联机](/guide/connect#连接失败排查)。

**装了 Radmin VPN / Hamachi 后联机异常**

这类虚拟网卡软件会抢占路由。启动器已自动规避常见问题，仍异常时建议先退出它们。

## 界面

**界面卡顿、动画掉帧**

设置 → 外观：降低 **组件材质**（液态玻璃/亚克力最吃性能）、关闭或调快 **动画**、限制 **最大帧率**。

**背景图 / 主题色怎么改**

设置 → 外观：背景支持自定义图片与模糊度；主题色支持自定义和"跟随背景（莫奈取色）"。
