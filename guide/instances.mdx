## 实例管理

"实例"就是一个可独立运行的 Minecraft 游戏副本——包含游戏本体、Mod、存档和专属设置。启动器的实例页面负责创建、安装和管理它们。

## 实例列表

侧边栏点击 **实例** 进入。列表支持：

- **搜索**：按名称快速过滤
- **筛选**：按加载器（Vanilla / Forge / Fabric / NeoForge / Quilt 等）或游戏版本筛选
- **固定到主页**：把常用实例固定到主页，配合主页的启动栏一键启动
- **批量操作**：多选后批量删除

## 安装新游戏

三种方式：**通过下载**全新安装、**安装整合包**一键配齐、**迁移已有游戏**收编其他启动器装好的 .minecraft（支持多游戏目录、扫描导入、文件补全）。

详见 **[安装游戏](/guide/installing-games)**。

安装任务进度见[下载中心](/guide/downloads)。完成后实例出现在列表中，点击即可进入详情页。

## 实例详情

点击任一实例进入详情页，包含以下分区：

| 分区 | 说明 |
| :--- | :--- |
| **概览** | 实例信息一览与快捷操作（启动、打开文件夹、固定到主页） |
| **设置** | 实例名、图标、Java 运行时、完整性校验、版本隔离、关联账户 |
| **游戏设置** | 启动参数、内存等游戏级设置（可跟随全局设置） |
| **存档** | 单人世界列表，支持重命名 / 备份 / 删除 |
| **截图** | 游戏内截图浏览 |
| **Mod** | 模组列表，支持启用/禁用、更新、批量删除，一键跳转资源中心搜索 |
| **资源包** | 资源包管理 |
| **光影包** | 光影包管理 |
| **数据包** | 世界数据包管理 |
| **投影原理图** | Litematica 原理图文件管理（预览 / 重命名 / 删除） |
| **服务器** | `servers.dat` 中服务器列表 |

## 版本隔离

**版本隔离**开启时，每个实例的 Mod、存档、资源包、光影等数据存放在实例自己的目录中，互不干扰；关闭时则共用游戏目录下的公共文件夹（老式整合包习惯）。

- 在 **实例详情 → 设置** 中可为单个实例开关版本隔离；
- 在 **设置 → 基础设置** 中修改全局默认值。

一般建议保持开启。

## 删除实例

在实例列表多选后批量删除，或在实例详情中删除。删除仅移除启动器中的实例记录与对应版本目录，**存档等个人数据请提前备份**。
