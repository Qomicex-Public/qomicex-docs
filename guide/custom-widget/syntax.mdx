## QWidget XML 语法

QWidget 是单文件 XML。根元素固定为 `Widget`，其余元素分为布局、控件、数据/资源、触发器、函数和嵌套引用。

## 根元素

```xml
<Widget Name="每日新闻" Version="1.0.0" Author="示例"
        Description="可选说明"
        UpdateUrl="https://example.com/news.qwidget"
        LauncherVersion="1.4.0">
  ...
</Widget>
```

| 属性 | 必填 | 说明 |
| :--- | :--- | :--- |
| `Name` | 是 | 组件显示名，≤64 字符 |
| `Version` | 是 | 组件版本，用于在线更新提示 |
| `Author` | 否 | 作者 |
| `Description` | 否 | 描述 |
| `UpdateUrl` | 否 | 更新源，必须 https:443；不写时使用导入 URL |
| `LauncherVersion` | 否 | 最低启动器版本，见[版本要求](/guide/custom-widget/reference/version) |

## 命名

所有元素、属性、枚举值使用大驼峰：

- 元素：`Container`、`Text`、`TextBox`、`Widget.Using`
- 属性：`Value`、`Size`、`OnClick`、`EmptyText`
- 枚举：`Lg`、`Bold`、`Center`、`Json`、`Binary`

## 三种等价写法

同一个属性支持属性语法、内容语法、属性元素语法，三者等价；同一属性被两种语法同时赋值会报错。

```xml
<!-- 属性语法 -->
<Text Value="Hello" />

<!-- 内容语法（ContentProperty） -->
<Text>Hello</Text>

<!-- 属性元素语法 -->
<Text><Text.Value>Hello</Text.Value></Text>
```

ContentProperty 映射：

| 元素 | 内容对应属性 |
| :--- | :--- |
| `Text` | `Value` |
| `Button` / `Link` / `CheckBox` / `FilePicker` | `Text` |
| `TextBox` / `ColorPicker` / `Progress` / `Slider` | `Value` |
| `Select` | `Options`（JSON） |
| `Media` | `Source` |
| `Image` | `Src` |
| `Spacer` | `Size` |
| `Data` | `Url` |
| `String` / `Bool` / `Number` / `Binary` / `Resource` | 文本内容 |
| 容器类元素 | 子元素 |

属性元素可继续嵌套简单的属性赋值：

```xml
<Text>
  <Text.Size>Lg</Text.Size>
  <Text.Weight>Bold</Text.Weight>
  Hello Qomicex
</Text>
```

### 附加属性

`Grid` 的直接子元素支持 `Grid.Row`、`Grid.Column`、`Grid.RowSpan`、`Grid.ColumnSpan`：

```xml
<Grid Columns="2" Gap="2">
  <Button Grid.Column="1" Text="右侧" />
  <Button>
    <Grid.Row>1</Grid.Row>
    <Button.Text>下一行</Button.Text>
  </Button>
</Grid>
```

## 绑定

字符串属性都可以用 `{路径}` 插值；整个值就是一个绑定时保留原始类型。

| 命名空间 | 示例 | 说明 |
| :--- | :--- | :--- |
| `Data` | `{Data.News.Title}` | 数据源，未命名源为 `{Data.Title}` |
| `Resources` | `{Resources.AppName}` | 命名资源 |
| `Inputs` | `{Inputs.Keyword}` | 控件当前值 |
| `Results` | `{Results.Search.Items}` | 函数/命令/插件 API 结果 |
| `Children` | `{Children.Weather.Inputs.City}` | 嵌套组件只读状态 |
| `State` | `{State.Loading}` / `{State.Error}` | 组件运行状态 |

详见[数据绑定](/guide/custom-widget/reference/binding)。

## 动作

按钮、链接和触发器通过 `OnClick` / `OnChange` / `Action` 调用动作：

`Launch`、`SetDefaultInstance`、`OpenInstance`、`Navigate`、`OpenUrl`、`OpenFolder`、`Copy`、`SelectAccount`、`Install`、`Refresh`、`CallFunction`、`RunCommand`、`PluginApi`。

参数与示例见[动作参考](/guide/custom-widget/reference/actions)。

## 限制

- XML ≤256KB、深度 ≤16、元素 ≤1000。
- 数据源 ≤8 个；列表渲染 ≤200 项。
- 在线文本 ≤1MB、二进制 ≤8MB；本地二进制 ≤8MB。
- 嵌套深度 ≤5，单父组件 ≤20 个嵌套实例。
- 函数脚本 ≤64KB，超时默认 3 秒，最大 10 秒。
- 禁止 `DOCTYPE` / `ENTITY`；未知元素、未知属性、重复属性都会直接报错。
