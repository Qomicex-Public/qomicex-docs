## Webview 嵌入

`Webview` 用沙箱 iframe 嵌入 HTTPS 页面。

```xml
<Webview
  Src="https://example.com/embed"
  Height="320"
  Title="公告"
/>
```

## 属性

| 属性 | 可选值 | 默认 | 说明 |
| :--- | :--- | :--- | :--- |
| `Src` | HTTPS URL 或绑定 | 必填 | 仅允许 https:443 |
| `Height` | 80–4000 像素 | `320` | iframe 高度 |
| `Title` | 字符串 | `QWidget webview` | iframe 标题 |
| `Allow` | 字符串 | 见下 | iframe `allow` 特性 |

默认 `Allow`：

```text
fullscreen; autoplay; encrypted-media; picture-in-picture; clipboard-write
```

## 安全边界

- `Src` 必须是 HTTPS，且域名必须在编辑器中确认。
- iframe 固定使用 `sandbox="allow-scripts allow-forms allow-popups allow-popups-to-escape-sandbox allow-downloads"`，不包含 `allow-same-origin`，不能访问启动器页面。
- 不能嵌入 `file:`、`data:` 或本地路径。
- 目标站点可能通过 `X-Frame-Options` / CSP 禁止嵌入；这种情况下请使用 `OpenUrl` 在外部浏览器打开。
- 动态 `Src` 的域名仍需在组件 `hosts` 中确认，否则不会渲染。

## 布局

`Webview` 是固定高度块级元素。外层 `Container` 负责裁剪或滚动；不要依赖 iframe 自己改变组件高度。
