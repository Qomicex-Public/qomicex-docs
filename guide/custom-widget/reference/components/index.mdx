## 约定

- 属性、枚举值均使用大驼峰。
- 每个组件页包含：签名、属性表、内容语法、运行时行为、示例、坑。
- **属性值的含义、可选值和默认值统一见[属性值参考](/guide/custom-widget/reference/values)。**
- 全部可视节点还支持通用属性 `Target`（脚本定位）、`Visible`（显隐）与 `When`（尺寸断点），见 [QWidget XML 语法](/guide/custom-widget/syntax#通用节点属性)。
- 通用语法见 [QWidget XML 语法](/guide/custom-widget/syntax)。
- 绑定、动作、版本要求分别见[数据绑定](/guide/custom-widget/reference/binding)、[动作参考](/guide/custom-widget/reference/actions)、[版本要求](/guide/custom-widget/reference/version)。
