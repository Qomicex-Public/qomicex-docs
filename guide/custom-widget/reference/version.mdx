## 版本要求（LauncherVersion）

`LauncherVersion` 声明组件要求的最低启动器版本。适合依赖较新插件 API、Data 类型或动作的组件。

## 写法

```xml
<Widget Name="新版组件" Version="1.0.0" LauncherVersion="1.4.0">
  ...
</Widget>
```

支持：

- `1`
- `1.4`
- `1.4.0`
- `1.4.0-beta.1`

## 运行时行为

- 启动器版本 ≥ 要求版本：正常渲染。
- 启动器版本 < 要求版本：显示错误占位「需要启动器 X 或更高版本（当前 Y）」，不执行组件内容。
- 无法获取启动器版本（例如浏览器调试环境）：不做版本拦截。
- 嵌套组件各自检查自己的 `LauncherVersion`。

## 编辑器

信息面板显示：

```text
LauncherVersion: 1.4.0 (1.5.2)
```

当前版本低于要求时标红。

## 与其他版本号的区别

| 字段 | 作用 |
| :--- | :--- |
| `Widget.Version` | 组件自身版本，用于在线更新提示 |
| `LauncherVersion` | 要求的最低启动器版本 |
| `UpdateUrl` | 组件更新地址 |

## 建议

- 只使用当前稳定版已提供的 API 时，可以不写。
- 使用新动作、新 Data 类型或新 Host API 时，写最低版本。
- 组件更新引入更高要求时，同步提高 `LauncherVersion`。
