## 常见名词一览

启动器文档中反复出现的名词，在此统一解释。

## 游戏与实例

| 名词 | 解释 |
| :--- | :--- |
| **实例** | 一份可独立运行的游戏副本（游戏本体 + Mod + 存档 + 设置）。一个实例对应 `versions/` 下的一个版本目录 |
| **游戏目录** | 俗称 `.minecraft`，存放游戏文件的根目录；启动器支持同时管理多个游戏目录 |
| **数据目录** | 启动器自身的配置、缓存、日志存放位置，与游戏目录分开 |
| **版本隔离** | 让每个实例的 Mod、存档、资源包等数据互相隔离的机制，避免多实例文件混在一起 |
| **补全文件** | 扫描实例缺失的游戏文件（libraries、assets、client.jar）并自动下载 |

## 加载器与整合包

| 名词 | 解释 |
| :--- | :--- |
| **Vanilla（原版）** | 不带任何加载器的官方原版游戏 |
| **加载器** | 在原版之上加载 Mod 的框架：**Forge**、**Fabric**、**NeoForge**、**Quilt**。不同加载器的 Mod 一般不通用 |
| **Mod** | 修改游戏行为的模组，分加载器安装 |
| **整合包（Modpack）** | 预配置好的完整游戏环境：游戏版本 + 加载器 + 全套 Mod + 设置，一键安装 |
| **资源包** | 替换游戏外观音效（旧称"材质包"） |
| **光影包** | 配合光影加载器实现光照/阴影效果 |
| **数据包** | 世界层面的原版数据扩展，随存档走 |
| **原理图** | Litematica Mod 的建筑蓝图文件 |

## 账户与认证

| 名词 | 解释 |
| :--- | :--- |
| **微软登录** | 正版 Microsoft 账户 OAuth 授权 |
| **离线登录** | 只验证用户名，用于单机或离线服务器 |
| **外置登录（Yggdrasil）** | 第三方认证服务（如 LittleSkin、统一通），以自有账户体系模拟正版验证 |
| **统一通** | 一个 Yggdrasil 外置登录服务的名称 |

## 联机

| 名词 | 解释 |
| :--- | :--- |
| **房主** | 创建联机房间的玩家，负责管理玩家与 Mod 清单 |
| **房间码** | 房主分享给朋友的一串代码，凭它加入房间 |
| **NAT** | 路由器的地址转换类型，决定 P2P 直连的难易；严格 NAT 下可能需要中继 |
| **Mod 一致性** | 加入房间前启动器比对房主与你本地的 Mod 清单，避免因 Mod 不同而崩游戏 |

## 诊断

| 名词 | 解释 |
| :--- | :--- |
| **mclo.gs** | 公共日志分享服务，把长日志变成短链接，方便贴在 issue/聊天里 |
| **JVM 参数** | 传给 Java 虚拟机的启动参数，常用于调内存与垃圾回收 |
