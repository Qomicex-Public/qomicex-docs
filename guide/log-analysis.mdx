## 日志分析

游戏崩溃或行为异常时，日志分析帮你从海量日志中定位问题。

## 两个入口

| 入口 | 位置 | 用途 |
| :--- | :--- | :--- |
| **日志分析页** | 侧边栏 → 日志分析 | 手动粘贴一段日志分析 |
| **崩溃分析** | 启动崩溃弹窗时自动触发 | 游戏崩溃后自动分析本次崩溃报告（无独立入口，也不在实例详情页） |

## 手动分析

- 复制日志文本（游戏控制台、`latest.log`、启动器实时日志窗口均可）
- 粘贴到日志分析页的输入框
- 点击 **分析日志**

启动器会识别出日志中的已知错误模式（崩溃堆栈、Mixin 冲突、Mod 缺失依赖、内存不足等），按严重程度（Critical → Error → Warning → Info）排序输出，并给出常见修复建议。

## 崩溃报告分析

游戏崩溃时启动器自动捕获崩溃报告并**立即开始分析**，无需点击任何按钮：

- 崩溃弹窗（**游戏异常退出**）出现时，分析已经自动完成
- 弹窗里只有 **复制全部** / **导出报告** 两个操作，诊断结果直接展示
- 报告会**自动**上传到 mclo.gs 生成短链接，弹窗中以徽标 + 二维码展示，方便求助时分享（无需你手动开启，也没有开关）

向他人求助时附带：崩溃分析结果的 **mclo.gs 链接** + 你刚装过/更新过的 Mod 列表。比直接截图"游戏闪退"高效得多。

## 实时日志

实例运行时，侧边栏 → **运行中**（或启动时的实时日志窗口）可以看到游戏输出：

- 按级别过滤（INFO / WARN / ERROR / DEBUG / FATAL / 其他）
- 关键字搜索
- 异常时 **停止游戏** 直接结束进程
- 实时日志窗口**没有导出按钮**；导出完整日志请到 **设置 → 日志**。
