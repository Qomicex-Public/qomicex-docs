## Settings reference

The settings page lives under **Settings (Settings)** in the sidebar, with category navigation on the left. This page explains each setting and its recommended value, category by category.

- **Global settings vs instance settings**: the launch settings on this page (memory, Java, JVM arguments) are **global defaults**; an individual instance can override them in Instance details → Settings (see [Instance management](/en/guide/instances)).
- The performance tuning deep dive (how much memory to give, which Java to pick, download acceleration) is in [Performance tuning](/en/guide/optimize).

## Launcher settings (Launcher settings) (basics)

| Setting | Description | Recommendation |
| :--- | :--- | :--- |
| Language | Interface display language | — |
| Data directory | Where launcher configuration and data are stored | Do not change unless you know what you are doing |
| Version isolation (Version isolation) | Store each instance's data separately (recommended) | ✅ On |
| Close launcher after start | Minimize or exit the launcher once the game starts | Your preference |
| Automatically report critical errors | Sends crash logs automatically to help improve the launcher (no personal content) | ✅ Recommended |
| Telemetry | Anonymous feature-usage statistics (opt-in, off by default) | Your choice |

## Launch settings (Launch settings)

- **Memory allocation (Memory allocation)**: `auto` lets the launcher compute it from physical memory, or you can set a maximum manually. **On machines with 8GB or less, prefer auto**; for large modpacks you can hand out 6–8GB
- **Default Java**: the global default Java runtime (instances can override it individually); if Java is not installed, use the one-click download in the Java section
- **JVM arguments (JVM arguments)**: extra launch arguments; you usually do not need to fill these in for a Large Modpack

## Download settings (Download settings)

See [Download center](/en/guide/downloads#download-acceleration). Open it from the **Download center (Download Center)** page in the launcher.

## Storage and cache (Storage & Cache)

- **Version list cache duration**: how long CurseForge / NeoForge version lists are cached; shorter = fresher, longer = fewer requests
- **Concurrency and TTL**: CurseForge request concurrency and cache lifetime; leave them alone in general

## Network settings (Network settings)

| Setting | Description |
| :--- | :--- |
| Proxy mode (Proxy mode) | Off / Follow system / HTTP(S) proxy / SOCKS5 proxy |
| Proxy address (Proxy address) | `host:port`, e.g. `127.0.0.1:7890` |
| Ignore SSL certificates (Ignore SSL certificates) | Skip certificate verification (fixes certificate hijacking by some proxies; it is a security risk, so enable it temporarily only while troubleshooting) |
| Parallel HTTP/1.1 (HTTP/1.1 parallel) | Force parallel downloads to use HTTP/1.1 for compatibility with some proxies |

The proxy here applies to **the launcher's own requests** (resource search, downloads, and so on) and does not change in-game networking.

## Java runtime (Java runtime) {#java-runtime}

- The list of scanned Java installations and the selection of the default runtime
- **Download Java (Download Java)**: downloads a matching JDK automatically (the official Mojang source is recommended), so you do not install Java by hand
- **Add manually (Add manually)**: point to a Java path already on your machine

| Setting | Description |

| Background (Background) | Custom background image (random supported), overlay opacity, blur |

| Window corners (Window corners) | Window corner toggle and radius (Windows) |
| Font (Font) | Global UI font |
| Watermark (Watermark) | Home watermark text toggle and content |
