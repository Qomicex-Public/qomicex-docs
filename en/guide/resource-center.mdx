## Resource Center

The Resource Center (Resource Center)brings together content from **Modrinth** and **CurseForge**, so you can search for and install mods, modpacks, resource packs, shader packs and more without opening a browser.

## Search for content

Click **Resource Center** in the sidebar to get started:

- Pick a category: **Aggregate / Mod / Modpack / Shader pack / Resource pack / Data pack / World**
- Enter keywords to search, or switch to **Favorites** to see the content you have saved
- Use filters to narrow results by **game version**, **loader** (Forge / Fabric / NeoForge, and more), or **source** (Aggregate / Modrinth / CurseForge / FTB / Technic)

## Install into an instance

On the content detail page:

- Click **Install**, then **select an instance** in the install dialog that opens
- Once an instance is selected, the version list only shows versions that match that instance's **game version + loader** — just pick one
- Track progress in the Downloads (Download Center)

The instance-first filtering automatically hides incompatible versions, so you won't install the wrong build.

## Modpacks

A modpack (Modpack)is a ready-to-play game environment: game version, loader, every mod, and configs in one package.

Select the **Modpack** category in the Resource Center, search, choose a version on the detail page, then click **Install**. The Launcher (Launcher)creates a new instance and downloads everything for you.

For full modpack coverage (local import, MultiMC migration, mod management, updates and export), see **[Modpack support](/en/guide/modpack-support)**.
