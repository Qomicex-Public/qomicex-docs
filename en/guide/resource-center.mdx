## Resource Center

The Resource Center（资源中心）brings together content from **Modrinth** and **CurseForge**, so you can search for and install mods, modpacks, resource packs, and shader packs without opening a browser.

## Search for content

Click **Resource Center** in the sidebar to get started:

- Pick a category: **Mod / Modpack / Resource pack / Shader pack / World**
- Enter keywords to search, or browse popular and recommended content
- Use filters to narrow results by **game version**, **loader** (Forge / Fabric / NeoForge, and more), or **source** (Modrinth / CurseForge)

## Install into an instance

On the content detail page:

- Switch to the **Versions** tab and choose a **game version + loader** combination that matches your Instance（实例）
- Click **Install** and select the target instance
- Track progress in the Downloads（下载中心）

The installer filters available versions by the instance you selected (game version + loader), so you won't install the wrong build.

## Modpacks

A modpack（整合包）is a ready-to-play game environment: game version, loader, every mod, and configs in one package.

Select the **Modpack** category in the Resource Center, search, choose a version on the detail page, then click **Install**. The Launcher（启动器）creates a new instance and downloads everything for you.

For full modpack coverage (local import, MultiMC migration, mod management, updates and export), see **[Modpack support](/en/guide/modpack-support)**.
