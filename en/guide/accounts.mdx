## Account management

The Launcher（启动器）supports several login methods, and all accounts are managed on the **Account management（账户管理）** page.

## Add an account

Click **Accounts** in the sidebar, then **Add account**, and choose a login method:

| Login method | Description |
| :--- | :--- |
| **Microsoft** | Official Microsoft login（微软登录）via the Microsoft OAuth flow; you authorize in your browser |
| **Offline** | Sign in with just a username, for singleplayer or offline servers |
| **Unified Pass** | The extchu Unified Pass（统一通） |
| **LittleSkin** | The LittleSkin skin site, using External login (Yggdrasil)（外置登录） |
| **Custom Yggdrasil** | Your own or a third-party auth server; just enter the server address (API Root) |

## Set a default account

The home launch bar and the launch flow use the **default account**. Set an account as default from the account list, or click the dropdown arrow on the account card on the home page to switch quickly.

The first time you launch the game, a wizard asks you to select or add an account. Just follow the prompts; you don't need to configure anything in Settings beforehand.

## Skins and capes

- **Microsoft / Yggdrasil accounts**: skins and capes load from the auth server; view and change them on the account details page (upload from a skin site or from a local file)
- **Offline accounts**: pick a skin from the skin library or upload a local skin file

## FAQ（常见问题）

- **Microsoft login（微软登录）says the token expired**: the account card is marked as expired. Click it to sign in again. If this happens at launch, a re-authorization window appears.
- **An offline account can't join an official server**: offline login can't join servers that require official authentication. Use Microsoft login instead.
- **Message says the account data file is corrupted**: a change in your machine ID can make the encrypted data undecryptable. Follow the prompt to add the account again.
