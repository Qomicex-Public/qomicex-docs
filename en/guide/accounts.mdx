## Account management

The Launcher supports several login methods, and all accounts are managed on the **Account management (Account Management)** page.

## Add an account

Click **Accounts** in the sidebar, then **Add account**, and choose a login method:

| Login method | Description |
| :--- | :--- |
| **Microsoft** | Official account login through the Microsoft OAuth flow; you authorize in your browser |
| **Offline** | Sign in with just a username, for singleplayer or offline servers (you can optionally enter a UUID; one is generated if you leave it empty) |
| **Yggdrasil** | External login. **Preset server** shortcuts (LittleSkin, Blessing Skin) are provided, or you can enter a custom server address; both OAuth and password modes are supported |
| **Unified Pass** | An authentication system used by some Minecraft servers; enter the server ID (for example `lilu`) |

<Note>
In some interface languages you must **sign in to at least one Microsoft account first** before you can add offline or third-party accounts; in that case the corresponding tabs are greyed out.
</Note>

## Set a default account

The home launch bar and the launch flow use the **default account**. Set an account as default from the account list, or click the dropdown arrow on the account card on the home page to switch quickly.

The first time you launch the game, a wizard asks you to select or add an account. Just follow the prompts; you don't need to configure anything in Settings beforehand.

## Skins and capes

- **Microsoft accounts**: the most complete options — upload a skin (with a choice of classic or slim arms model), reset your skin, and switch official capes. Skins are also refreshed automatically.
- **Yggdrasil / Unified Pass accounts**: only **Refresh skin** is available. If the account has a server address configured, a **Visit skin site** button also appears to manage skins on the external skin site. Uploading from inside the launcher is not offered.
- **Offline accounts**: the account details page offers no skin or cape actions.

## FAQ (FAQ)

- **Microsoft login says the token expired**: when an expired token is hit at launch or on entering the game, a Microsoft re-authorization window appears — sign in again as prompted. You can also sign in again manually from the account page for an expired account.
- **An offline account can't join an official server**: offline login can't join servers that require official authentication. Use Microsoft login instead.
- **Message says the account data file is corrupted**: a change in your machine ID can make the encrypted data undecryptable. Follow the prompt to add the account again.
