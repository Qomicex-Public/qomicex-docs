## Download mirrors

Qomicex provides several download acceleration Mirrors (Mirror) for mod resources. Using them is simple: **replace the domain in the original download link with a mirror domain**, leaving the path unchanged.

## Available mirrors

| Mirror (Mirror) | Address | Supported |
| :--- | :--- | :--- |
| Mirror 1 | [https://mirror.qomicex.dpdns.org/](https://mirror.qomicex.dpdns.org/) | Modrinth / CurseForge / Forge |
| Mirror 2 | [https://mirror1.qomicex.dpdns.org/](https://mirror1.qomicex.dpdns.org/) | Modrinth / CurseForge / Forge |

Failover across nodes is automatic, so pick any one; if one is unavailable, switch to another.

## Usage

### Modrinth

Original link:

```text
https://cdn.modrinth.com/data/AANobbMI/versions/mc1.16.3-0.1.0/sodium-fabric-mc1.16.3-0.1.0.jar
```

After replacing the domain:

```text
https://mirror.qomicex.dpdns.org/data/AANobbMI/versions/mc1.16.3-0.1.0/sodium-fabric-mc1.16.3-0.1.0.jar
```

### Forge / CurseForge

Original link:

```text
https://mediafilez.forgecdn.net/files/8685/162/jei-26.2-neoforge-30.24.0.176.jar
```

After replacing the domain:

```text
https://mirror.qomicex.dpdns.org/files/8685/162/jei-26.2-neoforge-30.24.0.176.jar
```

### Source domains that can be replaced

- `cdn.modrinth.com` / `cdn-alt.modrinth.com`
- `mediafilez.forgecdn.net` / `edge.forgecdn.net`

## How the launcher actually picks a source

By default the launcher prefers the public MCIM mirror (`mod.mcimirror.top`) and falls back to the QML mirror nodes and then the official sources when it is unavailable. This fallback chain is what **Settings → Download settings → Resource download source** controls — you never have to assemble URLs by hand.
