## Download mirrors

**QML-Mirror** is an acceleration mirror for Minecraft mods and dependency libraries, aimed at players in mainland China. It addresses the timeouts, single-thread throttling, and dropped connections that occur when connecting straight to overseas sources such as Forge, Fabric, or Mojang. The service runs on Tencent Cloud EdgeOne's global edge network.

Highlights:

- **Direct domestic access**: reachable over all three major Chinese networks without a cross-border hop.
- **Strong edge caching**: popular mods and libraries are cached at the edge, so repeat downloads are served from the edge.
- **Multi-threaded range support**: works with concurrent launcher downloads and gets past the official sources' single-thread limits.
- **Full loader coverage**: Forge, NeoForge, Fabric, Quilt, Legacy Fabric, Babric, Cleanroom, and Sponge.
- **HTTPS enforced**: the whole site is HTTPS + HTTP/2.

## How to call it

The mirror routes by **path prefix**: replace the domain in the original URL with `mirror.shenv.top` and prepend the prefix for that repository. The rest of the path stays the same.

For example, a Forge installer:

```text
# Original URL
https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.2.0/forge-1.20.1-47.2.0-installer.jar

# Mirrored URL
https://mirror.shenv.top/mc-forge/net/minecraftforge/forge/1.20.1-47.2.0/forge-1.20.1-47.2.0-installer.jar
```

## Architecture and performance

**Caching strategy**: immutable files such as `.jar` and `.pom` are cached at the edge for a long time. Metadata files such as `.xml` and `.json` use short caching or bypass the cache so you always get current version information.

**Origin fetching**: large file requests go straight through EdgeOne's native CDN path, fetching from origin and transferring in ranges without passing through an edge function. This lowers time to first byte (TTFB) and removes the single-thread bandwidth ceiling.

**Measured performance**: downloading an 8 MB Forge installer takes about 14 seconds directly from the official source, versus about 4.3 seconds through this mirror (single-threaded). A second download served from cache finishes in under 1 second.

## Relationship to the Qomicex Launcher

<Note>
The launcher now integrates QML-Mirror with a traffic-splitting policy: **mod loader metadata and installers** (Fabric/Quilt meta, the Forge installer and its maven dependencies — small, strongly cached files) go through QML-Mirror by default (prefix routing per the table above, with automatic fallback to the official source), while **mod files** stay on the official CDNs (with MCIM as the mirror fallback) — mod files are large and high-traffic, and routing them all through a community mirror would overwhelm the CDN, so the mirror is reserved for loader metadata and installers.
</Note>

## FAQ

**A download returns 404?** Check that the path prefix matches the mapping table. Some upstream repositories have an extra directory level (for example NeoForge dependencies under `/releases/`); the mirror rewrites those internally.

**Does the mirror log what I download?** No. It acts purely as a CDN cache node and does not record or inspect user activity.

**Is this an official service?** No. It is a community acceleration node maintained by an individual developer, and it has no affiliation with Mojang, Forge, or Fabric.
