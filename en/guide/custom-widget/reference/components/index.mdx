## Conventions

- Element names, attributes, and enum values use PascalCase.
- Every component page contains signature, attribute table, content syntax, runtime behavior, examples, and gotchas.
- **For value meanings, allowed values, and defaults, see [Attribute values](/en/guide/custom-widget/reference/values).**
- Every visual node also supports `Target` (script addressing), `Visible`, and `When` (size breakpoints); see [QWidget XML syntax](/en/guide/custom-widget/syntax#common-node-attributes).
- General syntax: [QWidget XML syntax](/en/guide/custom-widget/syntax).
- Bindings, actions, and version requirements: [Data binding](/en/guide/custom-widget/reference/binding), [Actions](/en/guide/custom-widget/reference/actions), [Version requirements](/en/guide/custom-widget/reference/version).
