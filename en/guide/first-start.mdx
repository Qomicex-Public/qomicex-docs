## First start

The first time you launch Qomicex, the **setup wizard（初始化向导）** opens and takes a few minutes to configure the basics.

## Two modes

| Mode | Best for | What it covers |
| :--- | :--- | :--- |
| **Quick setup** | Most users | Language, theme, Java, memory — the launcher recommends values, so you only confirm a few |
| **Custom setup** | Users who want full control | Everything above, plus download source, data directory and game directory |

## Wizard steps

- **Language** — Choose the interface language. It applies immediately and can be changed in settings at any time
- **Theme** — Dark / light, switchable in settings at any time
- **Directories** (custom mode only) — The data directory holds launcher configuration; the game directory (`.minecraft`) holds game files
- **Download source** (custom mode only) — Each source is speed-tested automatically and the lowest-latency one is selected; you can also tick "Auto-select the best"
- **Java runtime** — The launcher needs **Java 8 / 17 / 21** and scans your machine thoroughly. Missing versions can be downloaded online with one click
- **Memory** — **Automatic allocation** is recommended (calculated from available system memory); you can also set the maximum memory manually
- **Finish** — Review the configuration summary and start using the launcher

You can skip Java setup in the wizard, but **some game versions may not start** if your Java environment is incomplete. You can add them later in Settings → Java runtime.

No need to download anything again. On the home page, go to the instances page, click **Import（导入）** and select your existing `.minecraft` directory to take over existing versions. See [Install a game → Migrate an existing game](/en/guide/installing-games#migrate-an-existing-game).
