## Modpack support

A modpack is a complete, play-ready game environment: a pre-configured game version, loader, full set of mods and settings. The launcher fully supports the two major platforms and the mainstream packaging formats.

## Install a modpack

Three routes; see [Install a game → Install a modpack](/en/guide/installing-games#install-a-modpack):

- **Search and install from Resource Center** (online Modrinth / CurseForge modpacks)
- **Import locally** a CurseForge zip or a Modrinth `.mrpack`
- **Import a MultiMC / Prism launcher instance** (including zips with nested instance directories)

After installation a separate instance is created automatically and all dependencies are downloaded for you.

## After installation

- Modpack instances behave exactly like ordinary instances: open the details page to manage mods, worlds and settings
- Download tasks are visible in [Downloads](/en/guide/downloads); interrupted parts are completed automatically by the launcher
- **Pin to home** and launch in one click from the home launch bar

## Mod management

Manually adding or removing mods in a modpack is not recommended (it breaks the config expectations of the pack author). When you need small adjustments:

- Instance details → **Mods**: view the list and enable or disable individual mods
- If a required dependency is missing, the launcher prompts you to add it
- To add mods, use the [Resource Center](/en/guide/resource-center) and install the version that matches the instance

## Update a modpack

- **Online modpacks**: reinstall from the Resource Center details page when a new version is out, or use **Update** on individual mods inside the instance
- Bulk updates at mod level: instance details → Mods → **Update**

## Export a modpack

An instance can be exported as a modpack to share with friends: do it from the instance details page. The generated modpack contains the instance configuration and the mod list (personal data such as worlds is excluded, or optionally included).
