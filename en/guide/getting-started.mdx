## Quickstart

How to install the launcher and get started.

## Install

Get the installer for your system from the [official website](https://www.qomicex.top/) or the [GitHub releases page](https://github.com/Qomicex-Public/Qomicex.Tauri/releases/).

![Download page](/images/tutorial/download.webp)

Pick your **system** and **architecture**, then choose a **download source (Download source)**:

- In mainland China, the first and second sources are recommended; outside China, the third

## Quick start

- **Windows** — Run the `.exe` installer and follow the wizard. Launch from the Start menu when it finishes.
- **macOS** — Mount the `.dmg` file and drag Qomicex Launcher into Applications. On first launch, allow it under "Security & Privacy".
- **Linux** — Run the `.AppImage` (`chmod +x` it first, then run it directly), or install the `.deb` / `.rpm` package with your package manager.

## Requirements

| Platform | Supported architectures | Minimum OS | Status | Installer / method |
| :--- | :--- | :--- | :--- | :--- |
| **Windows** | `x64`, `ARM64` | Windows 10 1809+ | ✅ | `.exe` (NSIS installer) |
| **macOS** | `x64` (Intel)<br></br>`ARM64` (Apple Silicon) | macOS 10.15+ | ✅ | `.dmg` / `.app` |
| **Linux** | `x64`, `ARM64`<br></br>`LoongArch64` (should work, untested)<br></br>`RISC-V 64` (experimental, in progress) | Ubuntu 20.04+ / Fedora 34+ / glibc 2.28+ | ✅  | `.deb` / `.rpm` / `AppImage` |
