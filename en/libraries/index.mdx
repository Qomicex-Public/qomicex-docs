## Library plugin docs

This section collects the docs for Library plugins (Library plugin), for developers who need to integrate those libraries. Each Library plugin has its own page or subdirectory.

> This section documents how to use ready-made Library plugins. It does not cover developing the plugin system itself; see the [Plugin development guide](/en/plugins) for that.

## Library plugin list

- [MarkdownLib](/en/libraries/markdownlib) — Markdown rendering library (`top.qomicex.markdown`) that provides `renderMarkdown` / `renderMarkdownInline` / `stripHtml`
- [MarkItDown](/en/libraries/markitdown) — Document-to-Markdown library (`top.qomicex.markitdown`) that provides `convertFile`, so the AI assistant can parse PDF / Word / Excel / PPT / images / audio
